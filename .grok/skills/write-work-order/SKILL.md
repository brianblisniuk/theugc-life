# Skill: write-work-order

Given the current frontier, produce a binding work order / contract.

Must include:

- Question the block answers.
- What it explicitly does not do.
- Source of truth.
- Invariants (especially authentication ≠ authorization).
- Acceptance criteria including required negative tests.
- Files/areas expected to change.
- What is out of scope.

Do not invent product decisions. If a required decision is missing from DECISIONS, stop and raise PRODUCT DECISION REQUIRED.
