# Skill: implement-work-order

Builder skill.

1. Create a dedicated git worktree for the branch.
2. Implement exactly the work order. No product decisions.
3. Add or update tests, including User A/B negative controls when private multi-user resources are touched.
4. Run local gates (typecheck, relevant tests).
5. Commit, push feature branch, open or update PR.
6. On auditor findings, correct in the same PR.
7. Never push to main. Never merge.
