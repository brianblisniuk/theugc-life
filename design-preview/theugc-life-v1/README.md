# theugc.life — prototipo UX/UI (Discover + Hotel Detail)

Versión de diseño interactiva en HTML, independiente del sitio en producción.

## Ver o descargar

1. Abre [index.html](./index.html) dentro de esta carpeta.
2. En la página de GitHub, usa el botón **Download raw file** (icono de descarga, arriba a la derecha del código).
3. Guarda el archivo como `theugc_life_ui_prototype.html`.
4. Haz doble clic en el archivo descargado para abrirlo en Chrome, Safari o Firefox.

El HTML es **autocontenido**: incluye CSS, JavaScript, gráficos SVG y contenido de demostración. No requiere compilación, servidor, instalación ni conexión a un backend.

Para obtener un ZIP desde GitHub, usa **Code → Download ZIP** en esta rama. Ten presente que ese ZIP incluye el repositorio completo de esta rama, no solo el prototipo.

## Funciones de demostración

- Vistas Discover y Hotel Detail.
- Tema Light / Dark.
- Visualización de planes Free / Pro / Max.
- Color principal **#DFFF4F**.
- Filtros, estados de hoteles, fichas, bloqueos premium y desbloqueos **simulados**.
- Adaptación responsive para móvil.

## Importante

No está conectado con Supabase ni con los servicios de envío de correo o pago. La información mostrada es de ejemplo y no representa datos reales de hoteles. No debe confundirse con la implementación de producción.

## Seguridad y alcance

Este prototipo vive en la rama `design/discover-hotel-detail-prototype-20261015` y **no modifica `main`**. Para integrarlo al producto real, reutilizar la arquitectura existente y la autorización del lado del servidor en vez de copiar datos de ejemplo.
