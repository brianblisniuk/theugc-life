# Design decisions — V12.2

These are the intentional UX positions consolidated from V3–V12.

| Decision | Chosen direction | What to avoid |
|---|---|---|
| Home | Max three immediate priorities, upcoming Trip, campaign progress, continue last search | News feed, statistics for their own sake, empty dashboard pretending to have data |
| Discover | Map above results, aligned three-column intelligence, Pro/Max filters, meaningful No data | Unexplained scores; weak giant white hotel rows; disabled behavior disguised as action |
| Hotel Detail | Creator Intelligence under the hotel title, contact highly prominent, clear action to pitch | Contact as minor afterthought; hidden real contacts in HTML |
| Contact | Professionally relevant named contact *when available*; 1 credit per hotel successful unlock | Guaranteeing a final decision-maker exists; charging failure or duplicate access |
| Trip | Dates, shortlist, confirmed vs pending accommodation coverage | A generic vacation planner; counting proposed stays as secured |
| Outreach | Contextual work initiative with/without Trip; inherits shortlist initially | Forced duplicate setup, generic batch blasts |
| Pipeline | Visually rich board + list + timeline; separate opportunity ID for each attempt | Boring flat list; conflating simultaneous attempts at one hotel |
| Pitch Studio | Hotel/Trip/recipient/portfolio in context; editable strong proposal; honest provenance | Guessing audience results or dates; invented sending |
| Inbox | Decisions first, not clone of Gmail; selected conversation shows opportunity context | Having to re-enter details to reply or log activity |
| Collaborations | Milestones, deliverables, deadlines, approval and contract association | “Agreed” treated as “deliverables approved” |
| Contract Review | Source on one side, issues on other, cite exact clauses | Fake legal certification or numeric contract scores |
| Profile | Quality of portfolio before follower count; hotel-facing view | Mandatory social metrics for new creators |
| Plans | Value and limits with transparent credit accounting; no unapproved prices | Pricing assumptions; Pro guaranteeing missing hotel metrics |
| Visual design | Archivo, light canvas, dark sidebar, lime action, readable density and mobile rules | Tiny text, neon overload, disconnected per-page UI |
| What is out of scope | Offer Builder, predictive ML scores, Hotel Claim Portal and production features | Building future products instead of closing the core creator journey |


> **Visual theme update (V12.2):** Midnight Studio dark mode is the approved design. Brand primary `#D1FF02`, dark canvas `#0C1110`, dark sidebar `#0A0E0D`, light accessible text. See `THEME_SPEC.md` and `design-system.html`. Original V12.1 screenshots are not part of this delivery.
